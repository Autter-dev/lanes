# Lanes

Run as many coding agents as you want on one repo, without them getting in each other's way. Every agent gets its own instant copy of your project, with dependencies ready and its own ports, URL and database.

```sh
npm install -g @autter/lanes
cd your-repo
lane
```

This package installs the `lane` command and the `laned` daemon. npm downloads only the build for your system (macOS, Linux or Windows, on x64 or arm64).

Other ways to install, such as Homebrew, winget, Scoop or a one-line script, are at [lanes.autter.dev/download](https://lanes.autter.dev/download).

Lanes is free and open source under the AGPL-3.0: [github.com/Autter-dev/lanes](https://github.com/Autter-dev/lanes).
